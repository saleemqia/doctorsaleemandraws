# drsallycare.com

Static site for Dr. Sally (child & adolescent mental health, online). Deployed by Cloudflare Pages from this branch (`drsallycare`), no build step, output directory `/`.

Still a pre-launch version: robots.txt, the `noindex` meta and the `X-Robots-Tag` header keep it out of search engines until the doctor approves the content. Remove all three at launch.
